# Aula 11 – Estratégias de Branching e Aula 12 – Pull Requests



## Descrição



Este repositório foi desenvolvido durante as atividades da disciplina de Técnicas de Versionamento de Código. O objetivo é praticar o uso do Git e do GitHub, aprendendo a trabalhar com branches, organizar alterações, realizar Pull Requests e corrigir problemas no projeto.



## Instalação



Para obter o projeto, é necessário ter o Git instalado. Em seguida, execute:



```bash

git clone https://github.com/celoise-sudo/aula11-branching.git

```



Entre na pasta do projeto:



```bash

cd aula11-branching

```



## Como utilizar



O repositório pode ser utilizado para acompanhar os arquivos e praticar comandos do Git, como:



- `git status`: verificar o estado dos arquivos.

- `git branch`: visualizar as branches.

- `git add`: adicionar arquivos para commit.

- `git commit`: registrar alterações.

- `git push`: enviar alterações para o GitHub.

- `git pull`: atualizar o repositório local.
